# مرکز عملیات برجیک

## بکاپ محلی و Google Drive

1. پس از دریافت تغییرات، اجرا کنید:
   `php artisan migrate --force`
2. در پنل مدیریت، «مرکز عملیات و بکاپ» را باز کنید.
3. مسیر محلی را به یک پوشهٔ مطلق خارج از `public/` تنظیم کنید. در Ubuntu بهتر است پوشه‌ای مانند `/var/backups/borjik` بسازید و دسترسی نوشتن را فقط به کاربر اجرای PHP بدهید.
4. برای MySQL/MariaDB ابزار `mysqldump` یا `mariadb-dump` باید در PATH باشد. در Ubuntu معمولاً با بستهٔ `mysql-client` فراهم می‌شود. در XAMPP ابزار داخل `mysql/bin` قرار دارد.
5. برای Google Drive، در Google Cloud یک OAuth Client بسازید، Drive API را فعال کنید و Refresh Token با مجوز نوشتن فایل‌های Drive دریافت کنید. Client ID، Client Secret، Refresh Token و در صورت نیاز Folder ID را در پنل وارد کنید. این اطلاعات در ستون رمزنگاری‌شدهٔ تنظیمات نگهداری می‌شوند.
6. ابتدا «اجرای بکاپ همین حالا» را بزنید و هم موفقیت محلی و هم شناسهٔ فایل ابری را در تاریخچه بررسی کنید.
7. بازیابی را در محیط جداگانه آزمایش کنید؛ صرف موفقیت ایجاد ZIP تضمین بازیابی کامل نیست.

بکاپ شامل خروجی دیتابیس و فایل‌های `storage/app/public` و `storage/app/private` است. فایل‌های بکاپ محلی طبق تعداد نسخه‌های انتخاب‌شده پاک‌سازی می‌شوند؛ حذف نسخه‌های قدیمی Drive در این نسخه انجام نمی‌شود.

## زمان‌بندی و پیامک

Laravel Scheduler باید روی سرور فعال باشد. در Ubuntu، خط Cron استاندارد Laravel را برای کاربر اجرای برنامه تنظیم کنید:

```cron
* * * * * cd /path/to/borjik && php artisan schedule:run >> /dev/null 2>&1
```

سپس «بکاپ خودکار» و «هشدار پیامکی» را در مرکز عملیات فعال کنید. بررسی سلامت هر پنج دقیقه اجرا می‌شود؛ بکاپ با تناوب انتخاب‌شده و حداکثر هر ساعت یک بار زمان‌بندی را بررسی می‌کند. هشدار SMS به اتصال پیامکی فعال و پیش‌فرض پنل وابسته است.

## محدودیت مهم مانیتورینگ

این بررسی‌ها سلامت برنامه و منابع قابل‌مشاهده از محیط PHP را ثبت می‌کنند. اگر کل VPS، شبکه یا دیتاسنتر از دسترس خارج شود، خود برنامه نمی‌تواند از داخل همان سرور پیامک ارسال کند. برای پوشش این حالت باید یک پایش بیرونی با مقصد هشدار مستقل نیز تنظیم شود. همچنین بازیابی بکاپ در این نسخه از داخل پنل انجام نمی‌شود تا خطر بازنویسی تصادفی داده‌های زنده وجود نداشته باشد.
