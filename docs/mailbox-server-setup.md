# راه‌اندازی یک‌بارهٔ مدیریت صندوق ایمیل

این بخش برای Postfix/Dovecot فعلی و دامنهٔ sabkhoneh.ir طراحی شده است. ابزار مدیریتی در scripts/sabkhoneh-mailbox است و باید با مالکیت root و مجوز محدود روی سرور نصب شود.

## مراحل

1. قبل از نصب از /etc/postfix/vmailbox، /etc/dovecot/users و /var/vmail/sabkhoneh.ir نسخهٔ پشتیبان تهیه کنید.
2. ابزار را به /usr/local/sbin/sabkhoneh-mailbox نصب کنید؛ مالک root و مجوز اجرایی فقط برای root باشد.
3. برای کاربر اجرای PHP-FPM فقط اجازهٔ اجرای همین فایل ثابت را از طریق sudoers تنظیم کنید. به PHP دسترسی عمومی sudo ندهید. نام کاربر وب را با بررسی سرویس PHP-FPM سرور خود مشخص کنید و پیکربندی sudoers را با visudo اعتبارسنجی کنید.
4. در مسیر پروژه اجرا کنید: php artisan migrate --force و سپس php artisan optimize:clear.
5. در پنل مدیریت، میزبان‌های IMAP و SMTP را تنظیم کنید و صندوق‌های از قبل موجود را با رمز فعلی‌شان ثبت کنید. رمزها در صفحه نمایش داده نمی‌شوند و در دیتابیس با رمزنگاری Laravel نگهداری می‌شوند.

ابزار فقط آدرس‌های @sabkhoneh.ir را قبول می‌کند. حذف صندوق، پوشهٔ پیام‌ها را به پوشهٔ پشتیبان منتقل می‌کند، نه اینکه فوراً آن را نابود کند. قالب فایل Dovecot روی سرور را قبل از اولین استفاده با کد ابزار تطبیق دهید؛ نصب‌های سفارشی ممکن است قالب متفاوتی داشته باشند. پس از راه‌اندازی، دریافت و ارسال را با ایمیل آزمایشی بررسی کنید.
