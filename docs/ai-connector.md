# اتصال امن هوش مصنوعی برجیک

## امنیت و راه‌اندازی

1. کد را deploy کن و migrationها را با فرایند معمول استقرار اجرا کن: `php artisan migrate --force`.
2. در پنل ادمین با مجوز `site.settings` وارد «اتصال هوش مصنوعی» شو و یک توکن با حداقل دسترسی لازم بساز.
3. توکن فقط یک‌بار نمایش داده می‌شود. مقدار کامل فقط در secret manager ابزار واسط نگهداری شود؛ در مرورگر، سورس فرانت‌اند، Git یا پیام‌رسان قرار نگیرد.
4. اتصال فقط روی HTTPS انجام شود. توکن‌های قدیمی را از پنل باطل کن؛ توکن‌ها هش‌شده ذخیره می‌شوند و تاریخ انقضای حداکثر ۳۶۵ روز دارند.
5. برای اتصال به ChatGPT باید یک ابزار واسط/Connector سازگار با ChatGPT ساخته یا پیکربندی شود که بتواند به API سایت درخواست بفرستد. صدور توکن به‌تنهایی ChatGPT را به این سایت متصل نمی‌کند.

## API نسخه ۱

تمام مسیرها زیر `/api/ai/v1` هستند و احراز هویت با هدر `Authorization: Bearer <TOKEN>` انجام می‌شود.

- `GET /overview` — دسترسی `read:overview`; آمار خلاصه و وضعیت آخرین بررسی سلامت و بکاپ.
- `GET /incidents?limit=10` — دسترسی `read:diagnostics`; فقط metadata رخدادها؛ متن خطا، trace، مسیر فایل، IP و شناسهٔ افراد برگردانده نمی‌شود. limit بین ۱ تا ۵۰ محدود می‌شود.
- `POST /actions` — دسترسی `actions:request`; JSON شامل `action` با مقدار `run_health_check` یا `run_backup` و `reason` الزامی است. پاسخ ۲۰۲ به معنی ثبت درخواست است، نه اجرای عملیات.

## تأیید عملیات

درخواست‌ها در صف پنل ذخیره می‌شوند. هیچ عملیات نوشتنی صرفاً با توکن اجرا نمی‌شود. مدیر باید وارد «اتصال هوش مصنوعی» شود، متن دلیل را بازبینی کند و کادر تأیید اجرای همان درخواست را انتخاب کند. تنها عملیات allowlist شده بررسی سلامت و اجرای بکاپ هستند. هر اجرا با حساب مدیر تأییدکننده در لاگ فعالیت مدیران ثبت می‌شود.

## نمونه درخواست

```sh
curl -H "Authorization: Bearer $BORJIK_AI_TOKEN" \
  -H "Accept: application/json" \
  https://YOUR-DOMAIN.example/api/ai/v1/overview
```

توکن را در این مستند یا در Git قرار نده. محدودیت نرخ API فعال است؛ برای خطاهای 401، 403، 422 و 429 پاسخ JSON بررسی شود.
