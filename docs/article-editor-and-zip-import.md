# مدیریت پیشرفته مقالات

## تصویر جلد
- در فرم مقاله فایل JPG، PNG یا WebP تا ۵ مگابایت انتخاب کنید.
- فایل در دیسک عمومی Laravel و مسیر `article-covers/` ذخیره می‌شود.
- URLهای قدیمی همچنان نمایش داده می‌شوند تا مقالات موجود نشکنند.
- سرور باید افزونه PHP `fileinfo` و لینک عمومی Storage پروژه را داشته باشد.

## ویرایشگر دیداری
ویرایشگر راست‌چین ابزارهای تیتر، پاراگراف، ضخیم، مورب، زیرخط، خط‌خورده، فهرست، نقل‌قول، تراز متن، لینک و undo/redo دارد. محتوا قبل از ذخیره با allowlist تگ‌ها و ویژگی‌ها پاک‌سازی می‌شود. برای نمایش محتوای HTML، قالب عمومی مقاله فقط از محتوای پاک‌سازی‌شده ذخیره‌شده استفاده می‌کند.

## ایمپورت ZIP
1. از صفحه مدیریت مقالات گزینه «دانلود قالب ZIP آماده» را بزنید.
2. فایل `articles.json` را با UTF-8 و همان ساختار نمونه ویرایش کنید. قالب با ۵ مقاله نمونه شروع می‌شود.
3. برای هر تصویر جلد، فایل را در پوشه `images/` داخل ZIP قرار دهید و مقدار `cover_image` را مثل `images/cover-1.jpg` بگذارید. اگر جلدی ندارد، مقدار را `null` نگه دارید.
4. فایل‌ها را دوباره داخل ZIP قرار دهید و با «آپلود و ایمپورت همه» ارسال کنید.

ساختار هر رکورد:
- `title`: اجباری، حداکثر ۲۰۰ نویسه
- `slug`: اختیاری؛ اگر با مقاله‌ای موجود یکسان باشد همان مقاله به‌روزرسانی می‌شود
- `excerpt`: خلاصه اختیاری تا ۵۰۰ نویسه
- `body`: اجباری، HTML ساده یا متن مقاله تا ۵۰٬۰۰۰ نویسه
- `status`: `draft` یا `published`؛ پیش‌فرض پیش‌نویس
- `published_at`: تاریخ قابل‌فهم برای PHP یا `null`
- `cover_image`: مسیر نسبی زیر `images/`، URL با HTTP(S)، یا `null`

محدودیت‌ها: ZIP تا ۱۰ مگابایت، مجموع حجم بازشده تا ۳۰ مگابایت، حداکثر ۱۰۰ مقاله، حداکثر ۳۰۰ ورودی ZIP و هر تصویر تا ۵ مگابایت. فقط JPG، PNG و WebP پذیرفته می‌شود. مسیرهای ZIP که تلاش به خروج از پوشه کنند رد می‌شوند؛ فایل‌ها مستقیماً extract نمی‌شوند.

## پیش‌نیازهای محیط
- PHP 8.2 یا بالاتر با افزونه‌های `zip`, `fileinfo` و `dom`.
- دسترسی نوشتن در دیسک عمومی Laravel.
- پس از استقرار در محیطی که هنوز لینک عمومی Storage ندارد، دستور `php artisan storage:link` را اجرا کنید.
