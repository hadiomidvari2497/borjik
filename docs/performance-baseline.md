# خط مبنای عملکرد برجیک

این نسخه نمونه‌های زمان‌دار از زمان پاسخ یک پرس‌وجوی ساده دیتابیس، رفت‌وبرگشت کش، نوشتن/خواندن فایل موقت، مصرف فضای دیسک و حافظه PHP را ذخیره می‌کند. نمونه‌ها هر پنج دقیقه اجرا و داده‌های بیش از ۳۰ روز حذف می‌شوند.

## فعال‌سازی

- اجرا کنید: `php artisan migrate --force`
- زمان‌بندی Laravel را مطابق راهنمای عملیات با `php artisan schedule:run` در Cron اجرا کنید.
- از پنل مدیریت > نظارت و امنیت > پایش عملکرد یک نمونه دستی بگیرید.
- برای Ubuntu VPS، در صورت پشتیبانی محیط PHP، load average و اطلاعات فضای دیسک نیز نمایش داده می‌شود.

## تفسیر درست

این اندازه‌گیری‌ها خط مبنای اولیه‌اند؛ زمان `SELECT 1` نمایندهٔ زمان همهٔ پرس‌وجوها نیست. حافظه ثبت‌شده حافظهٔ همان پردازش PHP است، نه کل RAM سرور. load average نیز ممکن است کل میزبان را نشان دهد. این نسخه هنوز زمان پاسخ endpointهای واقعی، slow query log، tracing درخواست‌ها یا بار هم‌زمان کاربران را اندازه نمی‌گیرد. قبل از بهینه‌سازی، دادهٔ کافی در ترافیک واقعی جمع‌آوری کنید و نتایج را با نسخه/زمان استقرار تطبیق دهید.
